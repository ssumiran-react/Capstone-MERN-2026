Project Tracking System:

This is a web-based application for developers to log their projects' histories 
and for supervisors to monitor the progress of each developer’s projects.
It is built with the MERN stack and styled using Bootstrap for a responsive, modern UI.

Features:
Developer Dashboard – Log new projects, update progress, and view project history.
Supervisor Dashboard – Oversee all developers’ projects and track progress.
Role-Based Access Control – Separate permissions for developers and supervisors.
Responsive Design – Optimized for desktop, tablet, and mobile devices.

Technology Full Stack Developer:
Frontend: React.js, Bootstrap, HTML, Javascript, CSS
Backend: Node.js, Express.js, Javascript
Database: MongoDB
Version Control: Git & GitHub
